Este aviso explica, en forma de borrador, qué datos puede tratar Lincefood y para qué se usan.

Responsable del tratamiento

Responsable: PENDIENTE de identificar.

Para consultas o solicitudes relacionadas con tus datos, escribe a berlinvielen2@gmail.com.

Finalidades

Los datos se utilizan para gestionar tu cuenta, atender pedidos, realizar pagos de prueba mediante Stripe Sandbox, enviar avisos opcionales y facilitar la recogida de pedidos mediante un código QR.

Datos que se pueden tratar

  • Correo electrónico, nombre y avatar asociados a la cuenta.
  • Pedidos y datos necesarios para gestionarlos.
  • Preferencias de notificación y token del dispositivo cuando activas los avisos.

Lincefood no guarda datos de tarjeta. Los pagos disponibles en esta versión son de prueba (Stripe Sandbox).

Permisos del dispositivo

  • Cámara: se usa para leer códigos QR de recogida.
  • Ubicación: es opcional y puede usarse para mostrar el mapa.
  • Biometría local: es opcional para autenticarte en el dispositivo. Lincefood no guarda tus datos biométricos.

Puedes administrar los permisos desde los ajustes de tu dispositivo. La ubicación y la biometría son opcionales.

Conservación

Los periodos de conservación de cada dato están PENDIENTES de definir.

Solicitudes sobre tus datos

Puedes solicitar la eliminación de tu cuenta y de los datos asociados desde la app o escribir a berlinvielen2@gmail.com. Consulta las instrucciones para solicitar la eliminación.
